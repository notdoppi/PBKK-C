## 1. Jelaskan perbedaan aplikasi desktop dengan aplikasi lain? Mengapa masih dibutuhkan
Aplikasi Desktop adalah sebuah software yang dijalankan secara lokal pada komputer. 

### Perbedaan Aplikasi Desktop Dengan Aplikasi lain

| APP Desktop | APP Web | APP Mobile |
| --- | --- | ---|
| dijalankan pada komputer kita menggunakan resource local komputer | dijalankan memalui browser web yang memiliki backend server | dijalankan pada OS handphone |
| dapat berjalan offline tanpa internet | membutuhkan Internet untuk menggunakannya | umumnya membutuhkan internet tetapi ada juga yang bisa offline |
| tergolong cepat dan responsif | membutuhkan Internet sehingga bergantung pada kecepatan internetnya | cukup cepat tetapi tergantung device yang digunakan |

### Mengapa masih dibutuhkan?
Aplikasi Desktop masih dibutuhkan karena dapat memanfaatkan potensi penuh dari hardware (komputer) secara langsung. Ada beberapa case yang masih membutuhkan aplikasi ini, sebagai contoh, sistem kasir. Kenapa sistem kasir menggunakan aplikasi desktop? karena dapat berjalan secara offline dan hasil rekap data jelas.

## 2. Tuliskan problem yang akan diselesaikan oleh aplikasi yang kamu buat? Definisikan fitur aplikasi yang merupakan solusi dari problem tersebut.
Salah satu problem yang dapat diselesaikan oleh aplikasi kita adalah adanya tab **Live Scoring** yang dapat membantu audience/penonton untuk melihat skor pertandingan yang sedang berlangsung. Pada tab live scoring ini, kita dapat melihat skor dari masing masing tim, Babak yang sedang berlangsung, dan juga durasi yang sudah berjalan dari pertandingan tersebut. Dengan adanya live scoring ini, audience/penonton dapat melihat score tim kesayangan mereka secara real time.
